# Hub ESDESIGN

Herramientas internas en HTML. Cada herramienta es un archivo suelto dentro de una carpeta.

- `index.html` — portada con enlaces a las herramientas.
- `admisiones/propuesta-economica.html` — calculadora de propuesta económica.

Para añadir una herramienta: subir el .html a una carpeta y enlazarlo desde `index.html`.
Para actualizar una: sustituir el archivo por la versión nueva.
